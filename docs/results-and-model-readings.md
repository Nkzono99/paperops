# 結果とモデル説明の書き方を原著から読む

`paper-draft` の[配布用の手引き](../src/paperops/skills/paper-draft/references/results-and-model.md)を作るために読んだ箇所。
最初の3本は月面・プラズマと計算手法を扱う。追加の9本は、制御実験・計算・観測・未検出・行動の記述・予測誤差の
推定など、結果を信じる根拠が異なるものを選んだ。本文の該当箇所と、そこで使う図表を対象にした。
以下は原文の順序に沿った文の働きの要約で、各行の「残す理由」は編集上の判断である。

## モデルの仮定・自由度・評価値をたどる場合

| 原著・箇所 | 文の働き | 残す理由 |
|---|---|---|
| Couzin ほか (2005)、式(3)・図1a | 一部の個体だけに進みたい方向を与える → 個体は自身の選好と近傍との相互作用を重み付けする → 群れ全体の進行方向の精度を測り、群れの大きさと情報を持つ個体の割合に対する変化を示す。 | 非情報個体は誰が情報を持つかを知らない。この仮定を抜くと、リーダーを識別する能力を最初から与えた結果とも読める。[原著](https://www.nature.com/articles/nature03236) |
| Lorenz (1963)、§5・式(23)–(27) | 先行計算の特定条件で三つ以外の変数が減衰したことを挙げる → 三つの項を残した方程式と変数の物理的意味を示す → 強い対流では元の方程式との対応が期待できないと範囲を定める。 | 「三変数に簡略化した」の一文では、何を保存した近似かと、どこから先が適用外かが分からない。[原著](https://cdanfort.w3.uvm.edu/research/lorenz-1963.pdf) |
| Breiman (2001)、§3.1 | 復元抽出した標本で木を育てる → 各事例を、それを学習に使わなかった木だけで投票する → その誤分類率を汎化誤差の推定値とする。 | 投票に参加する木の条件が評価量そのものを定義する。「多数決で評価した」まで縮めると、学習に使った事例への当てはまりとも読める。[原著](https://www.stat.berkeley.edu/~breiman/randomforest2001.pdf) |

## 既存の指針をどこで直したか

- 初版の「何と何を比較したか」という問いだけでは、Teevan らの事例の意味を回収できない。「何がどう進み、その分類の決め手は何か」も結果の問いに加えた。
- 「一致した」という要約では、Stone らでの誤差の大きさ、Silbert らでの力の伝達機構、Anscombe の例での分布の形が落ちる。本文に残すのは、一致する量と、それでも違う性質が分かる組み合わせとした。
- 境界を説明する Poppe らと、データから背景や誤差を作る Abbott ら・Breiman に共通するのは、ある操作が出力の意味を決めること。モデル説明には物理過程に加え、観測量・評価量をどう作ったかという問いを設けた。

分野と根拠の種類を意図して選んだ読解例であり、論文に各型が現れる頻度や、読みやすさの改善幅を測った調査ではない。
原著の文順を草稿の必須順序とせず、短縮の前後で読者が何を判断できるかを確かめるために使う。

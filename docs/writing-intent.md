# 書く前に意図と詳しさを決める

対象は、詳細が増えやすい結果章とモデル説明。既存の `BRIEF.md` の段落骨子を使い、書き手が「この箇所を、どこまで書けば終われるか」を執筆前に決める。著者が後で一節だけ書き直しても、詳しさを選んだ理由が引き継がれるようにする。

## 主張が決まっていても取捨に迷う理由

「補正後に誤差が小さくなった」は主張としては明瞭でも、段落の書き方は一つに決まらない。改善をもたらした操作を見分けてほしいなら中間の対照が要る。精度が用途の許容範囲に入ったと伝えたいなら、比較相手は許容値であり、関心はそれに最も近い条件に移る。同じ結果を説明しても、読者にしてほしい判断によって中心に置く証拠が変わる。

そこで骨子を作るときに、**この箇所に来た読者には何がまだ分からず、読んだ後に何ができれば十分か**を決める。「モデルを丁寧に説明する」のように、どんな材料を足しても達成に役立つ意図は、取捨の基準として弱い。「入力として固定した量と、モデルが予測した量を区別できる」なら、書き足す価値のある一文も、止める位置も決まる。

同じ仮定でも、読者に**知った上で先に進んでほしい**箇所では「〜を仮定した」で足りる。**妥当性を判断してほしい**箇所では、他に取り得る仮定と選択を左右した証拠が要る。**手法を再現してほしい**箇所では、選択を計算に反映する式や操作まで要る。一つの節の中に三つの詳しさがあってよい。

## 意図をどこに持つか

| 単位 | 書く前に決めること | 引き継ぎ方 |
|---|---|---|
| 論文 | 誰に、何を持ち帰ってほしいか。想定読者はこの分野の何を知り、この研究の何を初めて知るか。 | 既存の「問いと意義」「主張」「主要な発見」を使う。想定読者の違いで説明が変わるときだけ「問いと意義」に一行足す。 |
| 章・節・小節 | 親の問いのうち、この箇所が引き受ける部分はどこか。ここでは何を確かめ、何を既知として先へ進むか。 | 「段落骨子」の該当見出しに短く添える。親と同じ意図は引き継ぎ、問いや詳しさが切り替わるところだけ書く。 |
| 段落 | この一段落で読者にしてほしい判断、その決め手、説明の終点。用語を導入したり、次の比較を読めるよう準備するのも役割になる。 | 既存の第1文を骨子に残す。第1文だけでは取捨が二通りに読める段落にだけ、何を残しどこで止めるかを添える。 |
| 文 | この一文は、いまの読者に何を新しく可能にするか。次の式を読ませる、別の説明を退ける、適用範囲を狭める、といった具体的な用があるか。 | 執筆中に使って手放す。一文ごとの役割表は作らず、後の改訂でも迷う判断だけを段落骨子に戻す。 |

著者の意図は、会話で示した狙いと承認済みの BRIEF を出発点にする。どちらの意図を選ぶかで主要な発見や論文の重心が変わるときは、既存の BRIEF 承認の場で「Aならこの比較が主役、Bならこの例外が主役」と具体案を出す。局所の言い回しや分量は、執筆側が親の意図から決める。読者がどう解釈するかは書き手の見積もりなので、後の読者テストで直せる。

## 空の段落から何を採るか

最初に、段落の答えだけを仮に置く。次に「このままでは読者は何を区別できないか」を一つ具体化し、その区別をつける観察・条件・定義を足す。答えを覆す観察があれば、先に答えの方を直す。残りの材料は、想定読者がそれを使ってどんな別の読みを退けられるか、親の問いに沿って説明できたときに採る。「関連がある」「正しい」「補足になる」だけで、書く場所を与える必要はない。

自明さは書き手の感覚に任せず、**この読者が、この場所までに、何から分かるか**で判断する。

| すでに分かる理由 | この場所での扱い |
|---|---|
| 一般的な知識、または想定読者が知る分野の標準的な関係から分かる | その知識を使って先へ進む。手法の同定が必要なら名称・引用までとする。分野間で慣例が異なり、答えが変わる定義は一度書く。 |
| この論文が採った設定・定義から必然的に決まる | 非自明なのは、その設定を採ったという選択かもしれない。選択と効き方はモデル節に置く。結果節では、それを知った読者が導ける帰結の再説明を省く。拘束を実装できたかを検証する節なら、その帰結と実測との差が証拠になる。 |
| 前の段落、図表、式ですでに示されている | 必要な一点を指せば判断できるなら、そこで止める。図から全系列を読ませたり計算し直させたりしない。単独で読む図注には、図の解釈に要る条件を戻す。 |
| データを集計して初めて分かるが、細かな内訳で読者の判断は変わらない | 必要な傾向だけを言葉で示すか、段落の問いに使わなければ省く。再現・照合に使う内訳は、実際に参照できる表・図・補足に置く。枝葉に一律に付録を新設する必要はない。 |

「ほとんど」には二種類ある。**「ほとんどの試料で」**は件数の話なので、分母と例外を元データで確かめる。少数例や、例外が結論の境界を決める場合は「4条件のうち3条件」「低温条件だけ逆転」の方が短くて正確である。**「値はほとんど変わらない」**は大きさの話なので、何に比べて小さいかで決める。計器の分解能が意味を持つなら「差は分解能の範囲内」と書ける。判定閾値をまたぐ、ばらつきが大きく識別できない、分母や尺度が途中で変わる場合は、対応する値や不確かさを残す。不都合な一例にも、意図した主張が成立する範囲を変えるなら本文の場所がある。

## 同じ材料で詳しさが変わる例

以下は架空の測定器の例。従来法、入力補正だけ、入力補正と推定式を合わせた方法で、同じ試料群の平均誤差は 8、5、2 単位だったとする。

- **どの変更で改善したかを示す結果段落。** 「入力補正で平均誤差は8から5に下がり、推定式も替えると2に下がった。」中間の5が読者の区別したい二段階をつなぐ。元の値から計算できる減少率はここで足さない。この比較が直接示すのは、変更をこの順に加えたときの差である。
- **採用条件を満たすかを示す結果段落。** 仮に仕様が「各試料の誤差が3以下」なら、同じ平均値2を置いても答えは出ない。最大値や閾値を超えた試料の有無に根拠が要る。平均の内訳を短く言い換えてもこの穴は埋まらない。
- **補正法を説明するモデル段落。** 基準試料をゼロに合わせる方式なら、「基準試料を使って各回のゼロ点を決めた」で次の比較が読める。基準試料上の一致は設定の帰結で、独立した精度の証拠は別の試料での誤差にある。読者に再実装してもらう箇所では、ゼロ点の推定にどの測定を使ったかまで書く。

既存の BRIEF では、例えば次の分量で足りる。

```markdown
## 段落骨子

### 結果
入力補正で説明できる改善と、推定式の変更で加わる改善を読者が区別できればよい。
1. 入力を補正した後にも、推定式を替えると誤差が下がった。
   三条件を同じ試料で比べた値まで。各試料の一覧は表に任せる。
```

## paperops での受け渡しと試し方

- **`paper-brief`** が想定読者と、取捨が分かれる節の意図を上の骨子に残す。「載せないもの」は論文全体の取捨に使い続ける。ある節だけで省く値や、捨てた全ての文まで登録すると、台帳の保守が執筆を圧迫する。既存の BRIEF は、対象の節を次に書く機会に必要な一行を補えば使える。
- **`paper-draft`** は骨子から段落の問いと終点を取り、最初の草稿から材料を選ぶ。主要な発見は決め手となる証拠に結びつけ、前提や既出の事実は次の判断に使える詳しさで呼び戻す。数値を使う箇所の出典は `numbers.tex` に残す。
- **`paper-check`** は結果・モデルの読者テストで、意図メモを伏せて「この箇所を読んで何が判断できたか」「その決め手はどこか」「どこで判断が済んだか」を聞く。著者の意図と違えば構成を、根拠や例外を取り違えたら内容を、判断が済んだ後も同じ説明が続けば終点を直す。`paper-revise` では、著者が詳しさを直した理由が節固有なら、その骨子に戻す。他でも繰り返し使う好みは STYLE に残す。

この手順は 2.3.0 の skill に入っている。既存の BRIEF では段落骨子に自由記述で添えられる。

## 実原稿で見ること

採否を決めるために現行の書き方と並べて比べる試行は行わない。配布済みなので、比べても次にすることが変わらない。実原稿の草稿と改稿で、次の 3 点を見て直す。

- **骨子の一行が書かれたか。** 取捨が分かれる節に一行が無く、詳しさが揃わなかったなら `paper-brief` を直す。一行があるのに草稿の取捨に効かなかったなら `paper-draft` を直す。
- **読者の判断が意図と合ったか。** 読者テストで、初見の読者が主役を言い当てたか、対照・例外を落としていないか、「何が与えた条件で、何が結果か」を言えたか、判断が済んだ後の詳述がどこに残ったかを見る。短くなっても入力を独立な結果と誤読させれば失敗であり、必要な対照の一文が増えた改稿は成功しうる。
- **意図メモが膨らんでいないか。** 骨子に同じ判断の反復が増えたら、記録する階層を減らす。

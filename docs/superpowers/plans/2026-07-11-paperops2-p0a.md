# PaperOps 2 P0-A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PaperOps 2 の実装前提となる正本、責務、状態、互換条件、現行資産の disposition、評価 fixture 方針を固定し、typed Results hierarchy の残作業を閉じる。

**Architecture:** root 層の設計正本を RFC、三つの ADR、disposition matrix、evaluation fixture policy に分割する。`template/` の実装変更は行わず、既存 typed Results checker の no-fallback 挙動を専用回帰テストで固定する。各設計文書は root の deterministic documentation test で存在と必須判断を検査する。

**Tech Stack:** Markdown、Python 3.11+、標準 `unittest`、既存 checker test helper、Git、KUDPC `tssrun`

## Global Constraints

- GitHub Issue、push、release、PyPI publish は行わない。
- root 層と `template/` 層を混同しない。
- paperops-managed default、project-owned typed state、human-edited source、generated cache、local/confidential state、immutable publication snapshotを区別する。
- 一つの判断に writable な正本は一つだけとする。
- 五つの論理モデルを五つの巨大 YAML に固定しない。
- project-owned state を managed update で上書きしない。
- malformed typed state を legacy fallback で隠さない。
- JA/EN mirror、block ID、quantity、figure、citation、authoring intent、predicted result、analysis request、selective stale、living manuscript / immutable snapshot の互換性を維持する。
- raw reviewer text、credential、絶対 path、未公開 raw data、generated cache を tracked model に含めない。
- fixture は合成データだけを使い、schema 適合データ本体は P1 で追加する。
- テストはログインノードで直接実行せず、`tssrun -p gr20001b` で計算ノードへ送る。

```python
def test_disposition_matrix_names_every_current_skill_checker_and_make_target(self) -> None:
    text = self.read("docs/paperops2-disposition.md")
    skill_files = sorted((ROOT / ".agents" / "skills").glob("*/SKILL.md"))
    skill_files += sorted((ROOT / "template" / ".agents" / "skills").glob("*/SKILL.md"))
    checker_files = sorted((ROOT / "template" / "scripts").glob("check-*.py"))
    for path in [*skill_files, *checker_files]:
        rel = path.relative_to(ROOT).as_posix()
        with self.subTest(path=rel):
            self.assertIn(f"`{rel}`", text)

    for rel in ["Makefile", "template/Makefile"]:
        makefile = self.read(rel)
        targets = []
        for line in makefile.splitlines():
            if not line or line[0].isspace() or ":" not in line:
                continue
            target = line.split(":", 1)[0]
            if all(char.isalnum() or char in "._-" for char in target):
                targets.append(target)
        for target in targets:
            key = f"`{rel}::{target}`"
            with self.subTest(target=key):
                self.assertIn(key, text)
```

# 添削で著者が直したことと、別の論文にも使える判断

あるモデルの論文で、著者は比較表を外した後、同じ指標を図の panel にまとめる案を挙げた。
知りたかったのは条件ごとの値の一覧より、条件を変えたときの傾向だった。著者が選んだ形と、
その形で読者ができるようになったことを分けて読むと、表で個々の値を引くことが大切な論文にも判断を持ち込める。

## 原稿・図で判断が変わった例

| STYLE の例や添削で起きていたこと | 別の原稿なら何で決めるか |
|---|---|
| 手法別に節を分けたため、条件を一つだけ変えた対照が二つの節にまたがった。実験系ごとに方法と結果の題をそろえると、読者は対照を同じ節で追えた。 | 同じ対象の比較が途切れる場所を探す。異なる対象でも同じ機構が働くことが発見なら、機構でまとめる方が筋が通る。 |
| 新旧両方式とも寸法を変えたときの出力は安定していた。一方、方式を切り替えたときに差が出る量があった。 | 「どちらも設定に鈍感か」と「変更によって何が変わったか」は、それぞれ対応する対照で読む。 |
| 接合の有無を比べる図で電荷の更新幅が混在していた。両側を 0.25 s にそろえると、高さを変えたときの粒子電荷の変化幅は接合側で約 1.5% から約 0.3% に変わり、要旨も書き直した（11 月 14・17 日の改稿）。 | 容易に取り直せるなら、調べたい効果が読める設定で比較を組む。そろった側は使い、不足分は予想で書く。結果が来たら差の向きや大きさを読み直す。 |
| 結果を短くする過程で、観測の終盤を指す語が定常状態にも読めるようになった。別の論文では「対照より小さい」を「時間とともに減った」と読めた。 | 文の動詞から比較相手を言い直す。例えば試料の値が 3 から 5 に増え、同時刻の対照が 6 なら、「増えた」と「対照より小さい」が両方正しい。 |
| モデルの説明で、候補ごとに必ず満たす式と、候補の良し悪しを測る量が一列に並んでいた。 | 入力から採用までをたどり、式で求める未知数と、解いた後に残りうるずれを指す。条件が複数ある付録では、読者が一つずつ照合できる形にする。 |
| 一枚の図の大半は試料を入れた系で、補助の panel だけが試料を除いた対照だった。著者が取り違えを指摘し、両方の panel に対象名を添えた。 | その取り違えを防ぐ表示をデータの近くに置く。panel の順序や面積は、どの比較や形を読み取りたいかで選べる。 |
| 要旨では先行モデルの特徴と今回の拡張が一文に詰まり、議論では実装上の制約が繰り返された。 | 要旨を読んで既知の部分と新規の部分を言い分けられるか。議論を読んで、制約が実際にどの用途を狭めるか、どの用途なら結果を生かせるかを言えるか。 |

## どこまでを共通の手順にしたか

「候補」には、付録の条件を箇条書きにする案や、議論を使い道で閉じる案があった。前者で困っていたのは
判定の各段階を文中から探す手間、後者で問われたのは末尾で同じ制約を繰り返す意味だった。項目数や
段落の順には、著者の案を受けて書き手が決めた部分もある。共通の手順には、この違いを判断できる例を採った。

「共有待ち」の図注の添削では、何を比べた図かを冒頭で知らせる形が繰り返し選ばれた。
単純な一対の比較なら、結果を先に述べるだけで対象も伝わる。多条件の図なら、比較する対象と量から入れる。
著者に好みがあれば、その図注の型を使う。配色の値や二軸の好みは著者に属し、特定の対訳は対象と分野で決まる。
要旨の語数には各投稿先の上限を使う。

一つの問いに一段落を使うこと、図をまたいで同じ系列の色をそろえること、限界を置く節を決めることは、
既存の手順で扱えていた。今回の追加は、既存の手順だけではどちらを採るか決まらなかった場面に絞った。

# Paperops Review

agent と同じ TeX 原稿を並行して添削するための VS Code 拡張です。

1. 原稿の通常のタブでコマンドパレットから **Paperops: 添削用タブを開く** を実行します。通常のタブに未保存の編集があれば先に保存します。
2. 開いた `results（添削）.tex` などのタブで `%>` コメントや本文を編集します。表示中は約 1.5 秒ごとに元の原稿を確認し、前回の原稿・入力中の内容・最新の原稿を使って独立した変更を統合します。
3. 通常の保存操作で元の原稿に反映します。VS Code の Auto Save を有効にしている場合はそのタイミングで反映します。agent が読むファイルは元の `.tex` です。

同じ箇所に異なる変更があれば、添削用タブに「添削」「編集開始時」「原稿」を表示します。その箇所を残したい本文に直して保存してください。競合マーカーが残る間は原稿への反映を保留します。先に別の端末で原稿が更新された場合は、保存時にも最新版と照合します。

UTF-8 の `.tex`（BOM、CRLF に対応）で利用できます。添削用タブは VS Code の仮想ファイルです。LaTeX ビルドや原稿からの相対パスを使う操作は通常の原稿タブで行います。Remote SSH では接続先に拡張をインストールしてください。

## パッケージ作成

このディレクトリで `npm ci`、`npm test`、`npx @vscode/vsce package` を実行します。生成した VSIX を「Extensions: Install from VSIX…」でインストールできます。

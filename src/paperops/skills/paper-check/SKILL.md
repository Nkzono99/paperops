# 伝わるかを確かめる

書いた本人は主張を知っているので、原稿を読み返しても伝わるかどうかは判断できません。主張を知らない読者に
読ませ、受け取った内容を BRIEF と比べます。正確さの照合は、それとは別の作業として行います。

## 読者テスト

1. **PDF を用意する。** `pops build` で最新の PDF を作る。

2. **初見の読者に読ませる。** この会話、`BRIEF.md`、`STYLE.md` を見ていない agent（subagent）に、
   `build/main.pdf` だけを読むよう頼み、次を尋ねる。PDF を読めない環境では `manuscript/` の TeX を渡す。
   予想を含む草稿でも同じに行う（色の付いた箇所も、得られた結果として読んでもらう）。

   ```text
   このファイルだけを読んで答えてください。repository の他のファイルは開かないでください。
   1. この論文の主張を 1 文で。
   2. その主張を支える発見を最大 3 つ。それぞれ根拠の図番号も。
   3. 読んでいて主張を見失った箇所、何のための段落か分からなかった箇所（節と段落）。
   4. Abstract だけを読んだ人は、1 の主張を言えるか。
   ```

3. **BRIEF と比べる。**
   - 1 が BRIEF の主張 1 文と同じ意味なら合格。
   - 弱い、または別の点を主張として受け取っていたら、題、Abstract、Introduction の最後の段落、
     Discussion の最初の段落、主図の caption に主張 1 文の内容が現れているかを見て、足りない所へ書く。
   - 2 に BRIEF の発見以外が挙がったら、載せないはずの結果が目立っているか、主要な発見が埋もれている。
     分量と位置を直す。
   - 3 で挙がった箇所は、段落の第 1 文をその段落の主張に書き直すか、段落を削る。
   - 読者の 1 文のほうが BRIEF より良い主張に見えたら、原稿を直さずに著者へ伝える。

4. **骨子を比べる。** `pops outline` の出力を BRIEF の段落骨子と並べる。骨子に無い段落、第 1 文が主張に
   なっていない段落、主要な発見より副次的な結果のほうが分量の多い節を見つけて直す。

5. **直したら、新しい読者でもう一度行う。** 前の版を読んだ読者は初見ではなくなる。
   2 回直しても主張が伝わらないときは、文章ではなく BRIEF（主張の立て方、載せるものの選び方）の問題として
   著者に伝える。

subagent が使えない環境では、初見の読者の代わりに `pops outline` の出力だけを上から読み、段落の第 1 文と
caption だけで主張 1 文と発見が言えるかを確かめる。初見の目より甘くなるので、その旨を報告に書く。

## 照合

主張を言い切るぶん、根拠との対応はここで確かめます。食い違いを見つけたら、文を曖昧にして合わせるのではなく、
数値か BRIEF を直します。主張そのものが根拠に支えられていないと分かったら、著者に伝えます。

数値・引用・図と本文の食い違いは、その場で直します。追加の計算や確認が要る弱点は、照合役や初見の読者が
挙げたものも含めて、`paper-predict` の「上乗せの検証を分ける」の 2 つの問いで分けます。主張が覆りうるものは
著者に伝え、賭けとして「これから要る計算」に載せます。主張の範囲を狭めるだけのものは、計算を求めずに
成立条件を直します。残りは「行わない検証」に 1 行残し、追加の計算や確認は求めません。

- **数値**: 本文の結果の数値が `numbers.tex` のマクロになっていて、マクロに出典があるか。Abstract と
  主要な発見に出る数値は、出典のファイルを開いて値を見比べる。`\pending` が残っていれば一覧にする。
- **予想**: まだ得ていない結果に基づく数値・文・図に、印（`\pred{}`、`figure.md` の `predicted`、BRIEF の
  `予想`）が付いているか。根拠が手元に無いのに印の無い記述を見つけたら、根拠を探すか、予想として印を付ける。
  予想そのものは誤りではないので、数を数えて報告に載せる。
- **発見と根拠**: BRIEF の発見ごとに、言い切り文が、挙げた根拠と成立条件のもとで成り立つか。
  成立条件が、決めた置き場に書かれているか。
- **図**: 本文が図について述べていることが、図から読み取れるか。全ての図が本文から参照されているか。
  `figure.md` の状態が `draft` のままの図は無いか。
- **文献**: 引用した文献が実在し、引用箇所の内容を支えているか。`\note{要出典: ...}` が残っていれば一覧にする。
- **build**: `pops build` にエラー、未定義の参照と引用が無いか。
- **内部名**: run id、script 名、directory 名、作業中の呼び名が本文と図に出ていないか。

## 報告

読者が受け取った主張 1 文、BRIEF との違い、直した点、照合で見つけた食い違い、発表までに残っているもの
（残っている予想の数、賭け、主張が覆りうる弱点）、著者の判断が要る点を短く伝える。
直さずに残した問題は `BRIEF.md` の未決に書く。

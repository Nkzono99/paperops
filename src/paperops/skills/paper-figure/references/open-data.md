# 公開データの用意

## 配置と収録範囲

既定の配置先は論文リポジトリ直下の `open_data/` とする。既存規約や明示指定があればそれに従い、シミュレーションリポジトリ側の配置にも対応する。`BRIEF.md`、`numbers.tex`、`figure.md`、寄託依頼から対象図と主要数値を選び、再現に必要な縮約データを選ぶ。CSV や TSV など文書化された軽量な可搬形式を採用し、相対パスと実体ファイルのコピーで構成する。シンボリックリンク、巨大な生出力、認証情報、非公開依存、非公開の研究ディレクトリ、ローカルの下書き、キャッシュ、ローカルパスは除外する。

## パッケージ構成

- `README.md` に想定読者、引用方法、アクセス手段、同梱の縮約データによる図再現手順、完全再計算の導線を記す。公開ツールのリポジトリやリリース URL、非公開シミュレータの承認済み連絡先や利用手順も明記する。
- `data/` にデータ本体とファイル・図の対応カタログを置き、出典（実行 ID や観測 ID、版）と、単位・基準座標系・対象区間・フィルタ・欠損値の扱い・前処理を記す。
- `scripts/` に再現スクリプト、環境と依存バージョン、実行コマンドを置く。
- `inputs/` に実際の入力と、分かる範囲で再開元を置く。
- `MODEL.md` に必要時のみ仮定とアルゴリズム上の限界を記す。
- `lean/` に既存の形式証明を含める場合のみ、固定ツールチェーンと検証コマンドを添える。
- `figures/` に必要時のみ軽量なプレビュー図を置く。

## 権利と寄託メタデータ

観測データや混合データでは配布権限を確認し、再配布できない一次データは出典と取得手順を記す。未確定の寄託メタデータ（タイトル案、著者、ORCID、ライセンス、引用表記、関連 DOI）はデータ本体と分離して管理する。権利条件、エンバーゴ、ライセンスの選定、アップロードと公開の承認は著者が行う。入力項目と操作手順は公式ガイドで確認できる。 [Zenodo のアップロードガイド](https://help.zenodo.org/docs/deposit/create-new-upload/)

## アーカイブと検証

外部寄託を行う場合は配布用アーカイブと `SHA256SUMS` を作成する。展開したコピー上で同梱のデータと明記した依存関係だけで対象図をすべて再描画し、主要な数値を再集計する。元の図や数値と照合し、差の判定に数値の許容幅を使った場合はその幅も伝える。あわせてリンクとチェックサムを検証し、検証範囲の限界と失敗箇所を記録する。

# improve-writing-harness

Use this skill when the repository structure, scripts, or agent workflow creates repeated friction during paper writing.

## Objectives

1. Describe the friction in concrete terms.
2. Decide whether the fix should stay in this repository or be escalated to the upstream template.
3. If the fix is project-local, implement the smallest improvement here.
4. If the fix is reusable, prepare material for `raise-template-feedback`.

## Inputs to inspect

- `notes/writing-log.md`
- `notes/open-questions.md`
- `.claude/skills/`
- `scripts/`
- `.github/workflows/`

# Glob: notes/**/*

## Session notes rules

- `notes/session-context.md` and `notes/handoff.md` are read by hooks at session start. Keep them current.
- Record durable decisions in `notes/decision-log.md`, not only in chat history.
- Session files under `notes/sessions/` use the format `YYYY-MM-DD-session.md`.
- `notes/todo.md` should reflect the immediate next 3-5 tasks, not a backlog.

# Glob: manuscript/**/*.tex

## Writing quality rules

- 主結果の文では、証拠が十分な場合に `may`, `might`, `could`, `suggest` へ逃げない。
- 不確実性は、主語や動詞を弱めるのではなく、scope / condition / remaining uncertainty として明示する。
- 各段落は 1 つの機能を持つ: context, claim, evidence, warrant, limitation, transition のどれか。
- Introduction は problem -> gap -> why now -> contribution -> roadmap を明示する。
- Results は作業順ではなく、claim を支える順に並べる。
- Discussion の冒頭で主要な take-away を再提示してから限界へ進む。
- ローカル run label、script name、directory name、artifact name を公開語として使わない。
- Figure caption は、claim、evidence、boundary が読者に見える形にする。
- 新しい主張を加えたら `notes/claim-evidence-map.md` に対応する evidence と scope を記録する。
- 新しい公開用語、略語、内部語の置換が必要な場合は `manuscript/mirror/terminology.yml` に記録する。

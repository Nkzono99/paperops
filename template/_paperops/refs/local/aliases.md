# ローカルパス別名

- `sim_run_main`: 本稿の主なシミュレーション出力
- `runops_main`: `_paperops/refs/links.toml` から参照する主な runops project
- `knowledge_topic`: トピック固有のメモや過去断片
- `external_data`: `_paperops/refs/links.toml` から参照する一般的な外部データディレクトリ
- `fig_src`: リポジトリ外にある編集可能な図表ソース
- `figure_sources`: `_paperops/refs/links.toml` から参照する編集可能な図表ソースディレクトリ
- `external_notes`: `_paperops/refs/links.toml` から参照する外部ノートディレクトリ

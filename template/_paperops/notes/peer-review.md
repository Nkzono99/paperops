# 査読・返答互換ビュー

このファイルは旧パス互換のために残している互換ビューである。新しいレビュー指摘の正本は `_paperops/review/feedback/`、レビューラウンドは `_paperops/review/rounds/`、返答は `_paperops/review/responses/` のカードに置く。俯瞰ビューは `_paperops/notes/views/peer-review.md` に置く。

人間の原稿レビューやプロンプト指示は feedback card にし、`upstream_routes` に従って claim / gate / evidence / request / manuscript へ遡らせる。

# 追加依頼互換ビュー

このファイルは旧パス互換のために残している互換ビューである。新しい追加解析・図表・実験依頼の正本は `_paperops/model/issues/analysis/`、改稿依頼の正本は `_paperops/model/issues/writing/` のカードに置く。俯瞰ビューは `_paperops/notes/views/research-requests.md` に置く。

paper 側で発生した request は、必要に応じて `_paperops/refs/links.toml` の外部 project link と接続し、実行後に関連する result / claim / manuscript block へ戻す。

\section{Method}

% block: method.structure.01
The harness centers the boundary among `story/`, `manuscript/`, `submission/`, and `_paperops/`, separating project-owned state from managed defaults.

% block: method.mirror.01
Each mirrored section uses shared `% block: ...` identifiers, while `manuscript/mirror/map.toml` records file-level correspondence.

% block: method.automation.01
Make targets and checker scripts stage bibliography validation, mirror checks, card coverage, and submission gates for the appropriate workflow phase.

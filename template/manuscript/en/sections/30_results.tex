\section{Results}

% block: results.traceability.01
Keeping writing state in `_paperops/workflow/` and `_paperops/notes/` makes it faster to reconstruct the manuscript context at the start of the next session.

% block: results.refs.01
Using `_paperops/refs/summaries/` alongside source cards improves reuse during related-work writing and citation drafting.

% block: results.mirror.01
Block-level correspondence makes it straightforward to detect which scientific content still needs to be mirrored into English.
